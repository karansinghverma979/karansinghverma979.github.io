Privacy Policy & Data Governance

Last Updated: October 2026 | Author: Karan Singh Verma

1. Overview & Fundamental Philosophy

This Privacy Policy applies to personal developer tools, open-source software, Model Context Protocol (MCP) servers, and companion utilities authored by Karan Singh Verma, including but not limited to the Antigravity Google Workspace Plugin, Play Console Hub, and local desktop utilities.

🔒 Sovereign Local-First Invariant

Our applications operate strictly on a local-first, sovereign architecture. We do not operate remote tracking servers, advertising networks, telemetry telemetry collectors, or external analytics datastores. All computations and credential storages run exclusively on your local workstation.

2. Google API Services User Data Policy Compliance

For applications integrating with Google Cloud Platform and Google Workspace APIs (including Calendar, Tasks, Gmail, Drive, Docs, Sheets, and People/Contacts APIs):

  • Local Processing Only: Data accessed through Google APIs is fetched directly into your local process memory to fulfill real-time assistant commands. Zero Google user data is ever transmitted to, cached on, or processed by any external intermediary server.
  • No Model Training: No user data, email contents, calendar entries, drive files, or contacts are ever used to train AI models or machine learning systems.
  • Credential Quarantine: OAuth 2.0 access and refresh tokens are stored exclusively on your local machine in quarantined credential directories (e.g. ~/.gemini/credentials/google-workspace/) with operating-system level file permissions.
  • No Third-Party Sharing: We do not transfer, sell, or disclose Google user data to third parties, advertising partners, data brokers, or external entities under any circumstances.

3. Data Retention & Revocation

Because all tokens and configurations reside on your physical computer, you maintain 100% continuous sovereignty over your data:

  • You can revoke API access at any time through your Google Account Permissions.
  • Deleting the local token file (token.json) or purging the application directory permanently removes all credentials from your system.

4. Security Architecture

We enforce least-privilege API scoping, standard PKCE OAuth 2.0 flows, and strict Dispatch Firewalls requiring explicit operator confirmation before executing outbound emails or destructive file modifications.
